# 🏗️ Module 2: Relational Database Concepts & Data Definition Language (DDL)

Welcome to the second module of my SQL learning journey! This repository focuses on the architectural design of relational databases and mastering Data Definition Language (DDL) to construct, modify, and manage structural table objects.

## 📝 Module Overview
In this module, I dived deeper into core relational database paradigms and their organizational importance across modern applications. I studied fundamental structural schemas, learning how entities, attributes, primary keys, and relationships map to physical tables.

Through practical, hands-on labs using MySQL, I mastered the process of building database tables using both graphical user interfaces (GUI) and executable SQL scripts. Furthermore, I learned how to modify the blueprint of a database structure using commands to add or change table columns, clear entire table datasets instantly, and safely tear down database objects when they are no longer required.

## 🎯 Learning Objectives Completed

* 📐 **Relational Schemas:** Described foundational relational database models, carefully mapping business entities to tables, data attributes to columns, and uniquely identifying records using **Primary Keys**.
* ⚡ **SQL Paradigm Partitioning:** Developed a clear understanding of the structural differences between **DDL** (Data Definition Language for structure) and **DML** (Data Manipulation Language for data rows).
* 🔨 **Structural Creation:** Programmed custom scripts using the `CREATE TABLE` command to deploy stable data schemas with exact data types and parameters.
* 🧼 **Schema Lifecycle Management:** Mastered the structural lifecycle of database tables by implementing modifications (`ALTER`), sweeping data cleanly while preserving schemas (`TRUNCATE`), and completely deleting tables (`DROP`).
