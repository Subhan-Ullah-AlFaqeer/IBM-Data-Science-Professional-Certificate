# 🗄️ Module 1: Introduction to Databases & Basic SQL

Welcome to the first module of my SQL learning journey! This repository establishes a foundational understanding of relational databases and core Structured Query Language (SQL) syntax for data manipulation and retrieval.

## 📝 Module Overview
In this module, I was introduced to the core architecture of databases and the foundational rules of SQL. I learned how to interact with relational databases using fundamental Data Manipulation Language (DML) and Data Query Language (DQL) operations.

Through structured hands-on labs, I mastered retrieving data columns using `SELECT` statements and learned how to filter and refine my query outputs using criteria in the `WHERE` clause alongside counting methods like `COUNT`, record restrictions with `LIMIT`, and duplicate filtering via `DISTINCT`. Furthermore, I gained practical experience modifying database records, learning how to write secure data insertions (`INSERT`), targeted record modifications (`UPDATE`), and safe record removals (`DELETE`).

## 🎯 Learning Objectives Completed

* 💾 **Database Foundations:** Defined the structural purpose of relational databases and the functional role of SQL in enterprise data ecosystems.
* 🔍 **Data Querying (DQL):** Programmed data retrieval queries using standard `SELECT` blocks to query specific structural columns from target tables.
* ⚙️ **Result Refinement:** Optimized search outputs by implementing filtering logic via `COUNT` calculations, `DISTINCT` value isolation, and `LIMIT` constraint pooling.
* 🛠️ **Data Modification (DML):** Managed database states by inserting clean rows via `INSERT`, altering exact cell strings or metrics using `UPDATE`, and removing old or redundant rows with `DELETE`.
