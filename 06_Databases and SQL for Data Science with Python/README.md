## 🗺️ Repository Structure & Module Index

This repository is strictly organized into **6 core modules**, mapping out a structured learning track from absolute beginner syntax to specialized engineering components. Click on any module link below to access its specific subdirectory README, lab documents, and script files:

### 📂 [Module 1: Introduction to Databases & Basic SQL](./Module%201)
* **Focus:** Fundamental data retrieval and modification syntax.
* **Core Skills:** Writing foundational commands (`SELECT`, `INSERT`, `UPDATE`, `DELETE`) and refining row outputs with `WHERE`, `COUNT`, `DISTINCT`, and `LIMIT` constraints.

### 📂 [Module 2: Relational Database Concepts & DDL](./Module%202)
* **Focus:** Structural schema architecture and table object management.
* **Core Skills:** Dissecting entities, attributes, and primary keys; partitioning **DDL** vs. **DML** operations; and executing scripts to `CREATE`, `ALTER`, `TRUNCATE`, and `DROP` database tables.

### 📂 [Module 3: Intermediate SQL (Patterns, Aggregations, & Sub-Queries)](./Module%203)
* **Focus:** Advanced dataset filtering, row mathematical adjustments, and layered evaluation queries.
* **Core Skills:** Wildcard text matching (`LIKE`), grouping results (`GROUP BY`, `HAVING`), ordering sequences (`ORDER BY`), applying built-in math/string functions, and nesting multi-table sub-queries.

### 📂 [Module 4: Accessing Databases Using Python (SQLite & SQL Magic)](./Module%204)
* **Focus:** Programmatic database connectivity within data science environments.
* **Core Skills:** Establishing active connections with Python database drivers, utilizing `%sql` and `%%sql` Magic tools inside Jupyter Notebooks, and using scripts to automate database operations.

### 📂 [Module 5: Real-World Data Analysis & Capstone Project](./Module%205)
* **Focus:** Applied data analysis against production-grade public datasets.
* **Core Skills:** Auditing physical schema details and translating complex, open-ended municipal questions (Chicago public schools, crime, and socio-economic datasets) into optimized analytics queries.

### 📂 [Module 6: Advanced SQL for Data Engineering](./Module%206)
* **Focus:** High-performance database operations and server-side automation (Specialized Engineering Track).
* **Core Skills:** Abstraction via virtual **Views**, procedural processing via **Stored Procedures**, pipeline isolation via **ACID Transactions**, and complex set combinations using relational **JOINs** (`INNER`, `LEFT`, `RIGHT`, `FULL OUTER`).
