# 🌆 Module 5: Real-World Data Analysis & Capstone Project (Chicago Datasets)

Welcome to the fifth and final module of my SQL learning journey! This repository contains the culmination of this course: a series of comprehensive data analysis investigations and an applied capstone project using multi-table datasets from the City of Chicago.

## 📝 Module Overview
In this module, I transitioned from synthetic sandbox environments to working directly with large, complex, real-world datasets. I was tasked with analyzing interconnected tables containing public information for the City of Chicago (including socio-economic indicators, public school performance metrics, and crime data). 

To solve realistic analytical problems, I learned how to deep-dive into physical schema architectures, audit table properties, and trace database relationships. This module heavily evaluated my capability to interpret open-ended business intelligence questions, translate complex logic requirements into clean, syntax-valid SQL queries, and execute high-performance analytical queries to extract exact figures.
