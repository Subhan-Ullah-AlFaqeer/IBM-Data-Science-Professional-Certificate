# 🔍 Module 3: Intermediate SQL (Patterns, Aggregations, & Sub-Queries)

Welcome to the third module of my SQL learning journey! This repository covers intermediate data retrieval operations, focusing on text matching, sorting, grouping, built-in functions, and nested evaluation queries across multiple tables.

## 📝 Module Overview
In this module, I advanced beyond simple table scans to master sophisticated data filtering, aggregation, and relational mapping. I learned how to leverage string patterns and variable ranges to find specific text strings and how to sort and group data cleanly within final result sets. 

Through highly interactive labs, I gained deep experience using SQL's native mathematical and string built-in functions to refine metrics on the fly. Furthermore, I expanded my logical approach to relational database querying by writing multi-layered sub-queries (nested select statements) and executing advanced queries that correlate and pool information across multiple distinct tables.

* 🔡 **Pattern Matching & Filtering:** Implemented advanced matching syntax using wildcards, specific string patterns, and range conditions to discover precise information.
