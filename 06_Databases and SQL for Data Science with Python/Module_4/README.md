# 🐍 Module 4: Accessing Databases Using Python (SQLite & SQL Magic)

Welcome to the fourth module of my SQL learning journey! This repository focuses on bridging the gap between database engineering and data science programming by connecting to relational databases directly from Python and Jupyter Notebooks.

## 📝 Module Overview
In this module, I learned how to establish programmatic connections between Python and relational databases. Working entirely within a Jupyter Notebook environment, I mastered how to automate data engineering tasks using both the native Python `sqlite3` driver and programmatic **SQL Magic** commands.

Through hands-on labs, I practiced instantiating connection pipes, creating structured tables, and performing massive data row insertions directly through code scripts. Furthermore, I learned how to write interactive query statements and leverage combined SQL and Python methods to explore, manipulate, and analyze datasets seamlessly for analytics workflows.
