In this module, you will apply the full data analysis workflow learned throughout the course. You will import, clean, analyze, and model real-world datasets to generate insights and predictions. The module includes a practice project and a final project that simulate real data analysis scenarios. You will also complete a final exam to demonstrate your understanding of key concepts in Python-based data analysis.
Learning Objectives

--- 
    ---> Write Python code to import data sets into a data frame
    ---> Generate appropriate Python code to wrangle data
    ---> Create boxplots and scatter plots using Python
    ---> Calculate R-squared and MSE using Python
    ---> Evaluate different data models by splitting data into training and testing sets
    ---> Perform polynomial transformation on data sets
    ---> Demonstrate comprehension and application of key data analysis concepts by answering questions based on real-world Python data workflows
