Data analysis is a foundational pillar for modern data professionals. I built this repository to master the capability of converting messy, unstructured datasets into polished, predictive data engines that drive automated business strategies and data-backed forecasts.

## 🗺️ Repository Structure & Full Lab Index

This repository is strictly partitioned into **6 core modules**. Below is the structural master directory linking each sub-module README to its specific interactive laboratory notebooks:

### 📂 [Module 1: Introduction to Data Analysis & Dataset Ingestion](./Module%201)
* **Focus:** Auditing structural metadata and establishing raw ingestion pipelines across multiple file types.
* **Core Notebook Workflows:**
    * 📂 [`01_DA0101EN-Review-Introduction.ipynb`](./Module_1/01_DA0101EN-Review-Introduction-20231003-1696291200.jupyterlite.ipynb) — *Package classification & structural auditing.*
    * 📂 [`02_Practice_data_loading.ipynb`](./Module_1/02_Practice_data_loading.jupyterlite.ipynb) — *Ingesting laptop specifications into Pandas DataFrames.*

### 📂 [Module 2: Data Preprocessing & Data Wrangling](./Module%202)
* **Focus:** Cleaning structural anomalies, normalizing continuous attributes, and encoding text features.
* **Core Notebook Workflows:**
    * 📂 [`01_DA0101EN-2-Review-Data-Wrangling.ipynb`](./Module_2/01_DA0101EN-2-Review-Data-Wrangling-20231003-1696291200.jupyterlite.ipynb) — *Imputation logic and data type casting structures.*
    * 📂 [`02_practice_data_wrangling.ipynb`](./Module_2/02_practice_data_wrangling.jupyterlite.ipynb) — *End-to-end data cleaning pipelines applied to Laptop pricing files.*

### 📂 [Module 3: Exploratory Data Analysis (EDA) & Statistical Insights](./Module%203)
* **Focus:** Exposing distributions, structural grouping, linear correlations, and significance mapping.
* **Core Notebook Workflows:**
    * 📂 [`01_Exploratory_data_analysis_cars.ipynb`](./Module_3/01_Exploratory_data_analysis_cars.ipynb) — *Market indicator trends and categorical aggregations using `.groupby()`.*
    * 📂 [`02_Exploratory_data_analysis.ipynb`](./Module_3/02_Exploratory_data_analysis.jupyterlite.ipynb) — *Pearson correlation matrix generation and Chi-Square distribution tests.*

### 📂 [Module 4: Predictive Modeling & Regression Development](./Module%204)
* **Focus:** Training supervised machine learning algorithms and diagnostics modeling.
* **Core Notebook Workflows:**
    * 📂 [`01_DA0101EN-4-Review-Model-Development.ipynb`](./Module_4/01_DA0101EN-4-Review-Model-Development-20231003-1696291200.jupyterlite.ipynb) — *Scikit-learn OLS estimator foundations and residual plot diagnostic curves.*
    * 📂 [`02_practice_model_development_laptops.ipynb`](./Module_4/02_practice_model_development_laptops.jupyterlite.ipynb) — *Bundling polynomial regressions with custom scikit-learn `Pipeline` objects.*

### 📂 [Module 5: Model Evaluation, Regularization, & Hyperparameter Tuning](./Module%205)
* **Focus:** Mitigating variance error, performing $L_2$ regularization, and automated grid searches.
* **Core Notebook Workflows:**
    * 📂 [`01_Model_Evaluation_and_Refinement_cars.ipynb`](./Module_5/01_Model_Evaluation_and_Refinement_cars.ipynb) — *Analyzing overfitting curves across multi-degree polynomial steps.*
    * 📂 [`02_practice_model_evaluation.jupyterlite.ipynb`](./Module_5/02_practice_model_evaluation.jupyterlite.ipynb) — *Executing cross-validated grid searches (`GridSearchCV`) to optimize Ridge alpha parameters.*

### 📂 [Module 6: End-To-End Capstone Project & Final Assessment](./Module%206)
* **Focus:** Complete independent deployment of the full pipeline against complex housing markets.
* **Core Notebook Workflows:**

* **Advanced Explanatory Plotting:** Crafting complex distributions, correlation heatmaps, box plots, and Kernel Density Estimation (KDE) curves to evaluate errors.
* **Regularized Machine Learning Pipelines:** Automating workflows using pipeline wrappers, scaling functions, Ridge regression stabilization, and multi-fold cross-validations.
