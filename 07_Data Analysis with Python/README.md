## 🗺️ Repository Structure & Full Lab Index

### 📂 [Module 1: Introduction to Data Analysis & Dataset Ingestion](./Module%201)
* **Focus:** Auditing structural metadata and establishing raw ingestion pipelines across multiple file types.

* **Focus:** Cleaning structural anomalies, normalizing continuous attributes, and encoding text features.
* **Core Notebook Workflows:**
    * 📂 [`01_DA0101EN-2-Review-Data-Wrangling.ipynb`](./Module%202/01_DA0101EN-2-Review-Data-Wrangling-20231003-1696291200.jupyterlite.ipynb) — *Imputation logic and data type casting structures.*

* **Core Notebook Workflows:**
