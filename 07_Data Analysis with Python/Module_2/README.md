# 🧼 Module 2: Data Preprocessing & Data Wrangling

Welcome to the second module of my Data Analysis track! This repository focuses on the data preprocessing pipeline—cleansing noisy records, engineering features, and transforming raw attributes into optimized mathematical representations ready for down-stream analytics and modeling.

## 📝 Module Overview
In this module, I mastered the core engineering techniques required to clean, transform, and format datasets prior to exploratory analysis or machine learning workflows. I explored the end-to-end data preprocessing pipeline, learning how to handle incomplete records defensively by diagnosing, dropping, or imputing missing cell values using **Pandas**.

Through technical hands-on labs, I corrected data format inconsistencies by converting attributes to their appropriate data types. I also implemented advanced numerical scaling techniques—including min-max scaling and Z-score standardization—to normalize continuous numerical variables for fair comparison. Furthermore, I practiced data discretization by binning continuous values into categorical groups. Finally, I converted text-based categorical columns into machine-readable numeric indices using label encoding and one-hot encoding. I applied this complete data-wrangling workflow to both the *Used Cars Pricing* and *Laptop Pricing* datasets.

## 🎯 Learning Objectives Completed

* 🔄 **Preprocessing Pipeline Orchestration:** Outlined and executed the key sequential steps within a production-ready data preprocessing workflow.
* 🛡️ **Missing Value Mitigation:** Diagnosed structural deficiencies within incomplete datasets, implementing advanced drop or imputation (mean/mode replacement) strategies.
* ⚙️ **Data Type Standardization:** Realigned data-type layouts across inconsistent columns to ensure computational compatibility during feature calculations.
* ⚖️ **Feature Normalization:** Applied data normalization principles (Min-Max scaling and Z-Score standardization) to scale numeric variables onto uniform scales.
* 📊 **Data Discretization (Binning):** Segmented continuous, high-variance numerical fields into clean, discrete category groups using Pandas binning techniques.
* 🔢 **Categorical Encoding:** Converted text-based categorical strings into structured numeric dimensions utilizing one-hot encoding dummy variables and label encoding indices.
