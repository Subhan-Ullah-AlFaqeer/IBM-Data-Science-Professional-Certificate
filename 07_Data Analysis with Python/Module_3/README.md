# 🔍 Module 3: Exploratory Data Analysis (EDA) & Statistical Insights

Welcome to the third module of my Data Analysis track! This repository focuses on Exploratory Data Analysis (EDA)—the critical phase of calculating descriptive statistics, diagnosing data distributions, mapping correlations, and executing statistical significance tests to uncover hidden patterns before feeding data into predictive models.

## 📝 Module Overview
In this module, I developed my ability to deeply audit and understand datasets through advanced EDA techniques. I explored the strategic role EDA plays in exposing data distribution patterns, verifying underlying assumptions, and isolating anomalies or outliers. 

Through highly interactive labs, I mastered calculating summary statistics to capture the central tendency and dispersion of numerical variables. I leveraged **Pandas** grouping methods to aggregate and isolate metrics across complex categories. To visualize these structures, I used **Matplotlib** and **Seaborn** to choose and build appropriate plot types for distributions and relationships. On the quantitative side, I implemented **Pearson correlation coefficients** to measure the linear strength between continuous features and executed **Chi-Square tests of independence** to evaluate statistical dependencies between categorical columns. I deployed these techniques to uncover trends inside the *Used Car Pricing* and *Laptop Pricing* datasets.

## 🎯 Learning Objectives Completed

* 🎯 **Strategic EDA Application:** Utilized EDA principles to check data sanity, locate structural patterns, and pinpoint extreme outliers before deploying predictive models.
* 📊 **Descriptive Statistical Profiling:** Evaluated summary statistics (mean, median, variance, and standard deviation) to detail the behavior and spread of core numeric variables.
* 🧩 **Categorical Aggregation:** Implemented the `.groupby()` function in Pandas to compute multi-layered aggregated statistics across distinct categorical groups.
* 📉 **Advanced Data Visualization:** Designed and generated targeted statistical plots (such as box plots, scatter plots, and histograms) to display data distributions and interactions.
* 🔗 **Linear Correlation Analysis:** Quantified relationships between continuous variables using the Pearson correlation coefficient to evaluate the strength and direction of feature interactions.
* 🏛️ **Categorical Significance Testing:** Executed Chi-Square tests to establish whether two categorical fields are statistically dependent based on observed vs. expected frequency matrices.
