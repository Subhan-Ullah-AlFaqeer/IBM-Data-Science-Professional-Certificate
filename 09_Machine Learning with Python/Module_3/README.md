# 🌲 Module 3: Advanced Supervised Learning — Classification, Decision Trees, & Ensemble Methods

Welcome to the third module of the **Machine Learning with Python** course! This repository documents my implementation and evaluation of advanced supervised machine learning algorithms. It covers multi-class classification, decision and regression trees, support vector machines (SVM), K-Nearest Neighbors (KNN), and high-performance ensemble frameworks like Random Forests and XGBoost.

---

## 📝 Core Technical Objectives
* **Categorical State Estimation:** Building multi-class classifiers to map inputs to multiple distinct target groups.
* **Hierarchical Decision Architectures:** Implementing sequence-based decision and regression tree models to optimize split nodes and map variable features.
* **Complex Boundary Fitting:** Deploying non-linear Support Vector Machines (SVM) and distance-based K-Nearest Neighbors (KNN) to isolate cluster divisions and anomaly states.
* **Ensemble Optimization:** Shifting from single-estimator limitations to robust multi-model pipelines using Bagging (Random Forests) and Boosting (XGBoost) to resolve bias-variance tradeoffs.

## 🎯 Technical Skills Architecture

### 📊 Tree & Vector Classification
* 🌿 **Entropy & Gini Information Splitting:** Configured optimization parameters to measure information gain at internal parent-child nodes.
* 🛡️ **Kernel Trick Engineering:** Projected multidimensional feature matrices into high-dimensional boundary spaces via radial basis and linear kernel operations.
* 👥 **Proximity Neighborhood Distance Metric:** Tuned $K$-factor hyperparameters and distance calculations to optimize neighbor-dependent classifications.

### ⚡ Ensemble Systems & Generalization
* ⚖️ **Bias-Variance Balancing:** Diagnosed error foundations to balance low-bias, high-variance base trees through ensemble aggregation.
* 🎒 **Bootstrap Aggregation (Bagging):** Engineered parallel Random Forests to reduce estimation variance by average-voting decorrelated sub-samples.
* 🚀 **Gradient Boosting (XGBoost):** Programmed sequential weak learners focused on minimizing prior residual loss gradients to maximize model accuracy.
