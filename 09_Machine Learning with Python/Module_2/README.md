# 📈 Module 2: Regression Analysis & Linear Classification Models

Welcome to the second module of the **Machine Learning with Python** course! This repository documents my mastery of fundamental regression frameworks and statistical classification techniques using the Scikit-learn engine to model continuous outputs and discrete categorical targets.

---

## 📝 Core Technical Objectives
* **Continuous Outcome Prediction:** Implementing simple and multiple linear models to map mathematical relationships between independent features and continuous dependent variables.
* **Non-Linear Mapping:** Evaluating polynomial and non-linear regressions to capture complex curve behaviors and non-linear patterns within datasets.
* **Probability-Based Classification:** Transitioning from continuous prediction to categorical classification using logistic boundaries to model binomial event probabilities.

## 🎯 Technical Skills Architecture

### 📊 Regression Modeling & Evaluation
* 📉 **Linear Regression Pipelines:** Programmed Ordinary Least Squares (OLS) routines to fit regression lines over multi-dimensional feature matrices.
* 📈 **Polynomial Complexity Scaling:** Transformed feature spaces to capture non-linear relationships without abandoning linear parameter structures.
* ⚖️ **Evaluation Metric Tracking:** Utilized Mean Squared Error ($MSE$), Root Mean Squared Error ($RMSE$), and $R^2$-score to score continuous predictive models.

### 🎯 Statistical Classification Engineering
* 📊 **Logistic Probability Modeling:** Applied Sigmoid activation functions to map numeric continuous outputs directly to binary categories.
* ⚡ **Classification Boundaries:** Configured decision thresholds to segment classifications and evaluated outcomes using confusion matrices.
* 🛠️ **Train-Test Optimization:** Implemented strict train/test splitting architectures to guarantee robust generalization and prevent over-parameterization.
