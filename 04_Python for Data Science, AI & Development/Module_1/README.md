# 🐍 Module 1: Python Basics & Development Environment

Welcome to the first module of my Python learning journey! This repository contains four comprehensive hands-on labs where I dive into the foundational concepts of Python programming and interactive computing.

## 📝 Module Overview
In this module, I began by exploring the fundamentals of Python programming. I identified the primary users and benefits of Python, while also learning about the diversity and inclusion efforts within the Python community. 

Next, I was introduced to the **Jupyter Notebook** environment, learning how to create, run, and manage code cells, as well as how to present and shut down notebooks. Moving into core programming, I wrote my first Python program and worked with essential data types such as integers, floats, and strings. As I progressed, I used expressions and variables to perform basic mathematical operations and practiced manipulating strings using indexing, escape sequences, and built-in formatting techniques.

## 🎯 Learning Objectives Completed

* **Community & Benefits:** Identified the key users and benefits of Python, along with the diversity and inclusion efforts of the global Python community.
* **Interactive Computing:** Mastered the purpose and functionality of Jupyter Notebooks to support interactive data science workflows.

* **Program Building:** Built programs in JupyterLab that demonstrate a solid understanding of types, expressions, variables, and string operations.
