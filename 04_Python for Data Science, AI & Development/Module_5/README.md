# 🌐 Module 5: Data Collection (APIs, HTTP, & Web Scraping)

Welcome to the fifth and final module of my Python learning journey! This repository focuses on real-world data collection techniques, including interacting with REST APIs, managing HTTP requests, parsing various file formats, and scraping unstructured web data.

## 📝 Module Overview
In this module, I explored a variety of technical frameworks used to gather data from both structured and unstructured external sources. I began by mastering the core mechanics of the **HTTP protocol**, studying how URL requests and responses interact under the hood using Python's `requests` library. 

From there, I dove into **Application Programming Interfaces (APIs)**, distinguishing between general APIs and REST APIs while utilizing `GET` and `POST` requests to send and receive structured data. I also learned how to extract valuable information from public websites using automated **web scraping** with the BeautifulSoup library, alongside parsing diverse file formats like CSV, XML, and JSON. 

As the capstone to this learning track, this module concludes with an applied practice project and a comprehensive review, validating my ability to integrate file I/O, control logic, Pandas, NumPy, and web extraction techniques into a unified data engineering workflow.
