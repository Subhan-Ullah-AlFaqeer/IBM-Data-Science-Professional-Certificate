This module explores various techniques for collecting data, focusing on the use of APIs, web scraping, and working with different file formats. By the end of this module, you will be equipped with the necessary tools and knowledge to collect data from different sources, both structured and unstructured. The module includes hands-on labs, optional content for further exploration, and a final comprehensive exam to test your overall understanding of the course.
Learning Objectives

---
---

    ---> Explore the HTTP protocol and interact with it using Python’s Requests Library for HTTP requests and responses.
    ---> Describe how URL request and response work in HTTP.
    ---> Invoke open-source APIs using Python.
    ---> Perform basic web scraping with Python and BeautifulSoup.
    ---> Work with different file formats such as CSV, XML, and JSON in Python.
    ---> Differentiate between general APIs and REST APIs.
    ---> Summarize how APIs send and receive information via GET and POST requests.
    ---> Develop a foundational understanding of Python programming by learning basic syntax, data types, expressions, variables, and string operations.
    ---> Apply Python programming logic using data structures, conditions and branching, loops, functions, exception handling, objects, and classes.
    ---> Demonstrate proficiency in using Python libraries such as Pandas and Numpy, and developing code using Jupyter Notebooks.
    ---> Access and extract web-based data by working with REST APIs using requests and performing web scraping with BeautifulSoup.
