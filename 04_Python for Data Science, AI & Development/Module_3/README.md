# ⚙️ Module 3: Python Programming Fundamentals & OOP

Welcome to the third module of my Python learning journey! This repository covers control flow, loops, functional programming, error handling, and the core concepts of Object-Oriented Programming (OOP) in Python.

## 📝 Module Overview
In this module, I built a strong foundation in core Python programming concepts essential for applied data science. I began with **conditions and branching**, learning how to use comparison and logical operators to control program execution flow. Next, I mastered **loops** (including `for` and `while` loops) to iterate over data sequences and automate repetitive tasks efficiently. 

Moving into functional programming, I explored **functions**, learning how to leverage Python's built-in tools and design my own user-defined functions to maximize code reusability and manage variable scope. I also tackled **exception handling**, a critical skill for building robust data pipelines that handle errors gracefully without crashing. Finally, I was introduced to **objects and classes**—the foundation of Object-Oriented Programming (OOP). I learned how to model real-world problems by defining classes, setting attributes, and creating methods to manipulate class instances.

## 🎯 Learning Objectives Completed

* 🔀 **Control Flow & Logic:** Described and classified conditional statements, using comparison and logical operators to guide branching behavior across structured scenarios.
* 🔄 **Iterative Automation:** Executed `for` and `while` loops effectively, identifying the appropriate scenario for each loop type to carry out iterative tasks.
* 🧩 **Functional Architecture:** Defined and applied user-defined functions with input parameters, explicit return values, and a clean understanding of local vs. global variable scope.
* 🛡️ **Defensive Programming:** Utilized exception handling constructs (`try`, `except`) to trap execution errors and sustain program robustness.
